# gpu-scraper

## Requisitos
Python 3.9 ou superior.

## Instalação

Linux / macOS:
  1. `python3 -m venv .venv`
  2. `source .venv/bin/activate`
  3. `pip install -r requirements.txt`

Windows (PowerShell):
  1. `py -m venv .venv`
  2. `.venv\Scripts\Activate.ps1`
  3. `pip install -r requirements.txt`

## Executar
  - `python3 main.py`
